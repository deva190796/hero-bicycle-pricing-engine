# Architecture Overview

Frontend:

* Streamlit

Backend:

* FastAPI

Database:

* MySQL

ORM:

* SQLAlchemy

Workflow:

User -> Streamlit UI

Streamlit -> FastAPI APIs

FastAPI -> SQLAlchemy

SQLAlchemy -> MySQL Database

Response -> Streamlit UI

Key Features:

1. Historical Price Tracking
2. Date-Based Price Calculation
3. Bicycle Configuration Storage
4. Interactive User Interface
5. REST API Architecture
