# Hero Bicycle Pricing Engine

## Overview

A full-stack bicycle pricing engine built using FastAPI, MySQL, SQLAlchemy, and Streamlit.

## Features

* Add bicycle components
* Manage component prices
* Track price history
* Calculate bicycle prices
* Save bicycle configurations
* View saved configurations

## Tech Stack

* Python
* FastAPI
* MySQL
* SQLAlchemy
* Streamlit

## Run Backend

```bash
uvicorn backend.main:app --reload
```

## Run Frontend

```bash
streamlit run frontend/app.py
```
